# Promotion Flow（Obsidian → Repo）

```
Idea（IDEA 状态） → Human Owner 选择 → requirement-to-task → Repo CURRENT_TASK（工程权威）
Human Note（稳定规则）→ Owner 决定 → Repo 规则文件
Retrospective 观察 → Observed+Confirmed Cause+Verified Resolution+Prevention Rule → Repo Lessons
Architecture brainstorm → 正式决定 → Repo docs/decisions/ADR-*.md
```
单向：Obsidian → explicit promotion → Repo。禁止双向可编辑工程同步。
