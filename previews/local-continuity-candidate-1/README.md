# ADS local continuity — 未发布候选包

目标：把本地 Git 核验、交接同步、checkpoint、resume 做成不依赖作者私人目录的两个 Skill 安装目录。这里只交付四项由 AI 读取执行的规范；不是自动执行引擎，也不是完整 26 能力版。

## 安装 / Install

前提：已有可读写文件、执行 Git 和项目测试的 AI 助手，以及一个经授权的本地测试仓库。当前安装验证使用隔离目录，不修改已有个人 Skill。

将 `skills/` 下的两个目录完整复制到运行时所使用的 skills 目录。目标如已有同名目录，停止并报告冲突，不覆盖、不删除；使用全新隔离配置进行试用。

对于支持项目级 Skills 的运行时，可把两目录放到它明确支持的项目目录。Hermes 使用其已配置 skills 目录；具体运行时安装与模型账号由用户自行配置，本包不提供凭据。安装后确认两个入口可见，并让助手实际读取入口及四个引用文件；发现入口不等于运行成功。

## 首次真实任务

把以下任务交给已安装候选包的助手：

> 在我授权的新建本地测试仓库，使用 ai-development-workflow 和 ai-software-legion，建立本地项目事实，然后新增 README 的运行说明，并运行实际验证。按包内规范做状态同步和一个本地 checkpoint；保留归档与证据，准备交给独立会话只读 resume。只允许本测试仓库写入及本地提交，不联网、不 push、不修改已有项目或已安装 Skill。Review/QA/人的验收没有发生就保持 OPEN。

下一会话从新生成的 Git 仓库和本包重新读取，执行 session-resume，不能依赖上一会话的历史。负例要在另一保留副本中制造，原正例不要破坏。

## 范围

只有本地 Git/仓库内看板；没有真实 Obsidian、生产审计、服务部署、模型路由、全部生命周期或所有运行时验证。缺权限、Git 错误、字段不全、分支/HEAD/状态/改动清单不符就停止并给出证据。

版本标识为 `local-continuity-candidate-1`，不是正式 Release，不修改 v0.1.1。反馈时说明候选包摘要、运行时、测试仓库版本、命令及退出码，不公开凭据或私人项目数据。

此目录是新写的候选规范，基于本项目公开 Git-first/交接约定整理；没有把私人 Skill 文件或历史演练全文复制到包里。保留公开项目 LICENSE 和 NOTICE。来源文件及摘要对照单独留在私有交付目录，不进入公开候选包。

本地候选内容、许可与归属说明、实际验收范围尚需项目维护者最终审阅；此文件不代表已获发布批准。
